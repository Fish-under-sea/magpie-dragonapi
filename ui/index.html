需要哪些权限

PAT scope 与对应能力
Scope用来做什么
profile:read读取账户资料（/api/user/self）
api_key:read列出已有钥匙
api_key:write新建 / 删除钥匙
api_key:reveal查看完整钥匙（reveal）
usage:read看用量与流水
wallet:read看余额与邀请

PAT 只能在浏览器里登录 DragonAPI 控制台后，于「安全 → 访问令牌」页创建； 插件无法代登录，也不会替你签发。
